## 纠偏数据与设置

数据集：`artifacts/data/noncontact_combined_20260925/`。
共 3,552 帧、3,516 个有效监督帧，包含 81 个不可见帧和 1,379 个近距离策略参与帧。
保留 3 个接触及 1 个超时回合的实际结果；物理失败前一秒不参与监督。
按完整回合、运动类型与不可见样本覆盖划分训练和验证，避免初始化模型训练场景泄漏到新验证集。

| 参数 | 100 轮训练值 |
|---|---|
| batch size / sequence length | 2 / 16（训练分组，视觉历史仍为 2 帧） |
| 学习率 / seed | 1e-4 / 0 |
| 动作损失权重 | 20 |
| 权重选择依据 | 验证动作损失 |
| 提前停止 | 关闭（patience=0） |
| 不可见帧 | 不监督动作，仍参与风险与可见性监督 |
| 训练耗时 | 约 113 分钟 |

采集日志、覆盖审计、上传与流程历史集中在 `training/data_preparation_20260925/`。
失败流程日志保留以说明数据覆盖检查和中断情况；一次性启动、上传脚本已清理。
初始数据验证集的可见性标签全部为 1，旧置信度损失接近零不能说明能识别出画。
历史 batch 基准中，batch 4 与 batch 2 吞吐接近，因此保留 batch 2。

## 100 轮离线结果

验证动作损失由首轮 0.00901708 降至第 99 轮的 0.00329172。
第 100 轮训练 / 验证动作损失分别为 0.00021491 / 0.00412874，约相差 19.2 倍；
风险损失分别为 0.00006226 / 1.1963，存在明显泛化差距。
第 99 轮动作 RMSE：前向 0.433 m/s、横向 0.396 m/s、垂直 0.084 m/s、偏航 0.039 rad/s。
这些离线指标不等同于闭环任务成功。
