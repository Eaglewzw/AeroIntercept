# 结果与验收

本文是 AeroIntercept 的**实验台账与验收基准**，回答"模型到底多好、证据在哪、离达标还差多少"：
完整记录历次训练与闭环评估的数据，定义正式验收标准，并如实列出当前局限。
README 的"闭环结果"一节只是当前保留权重的成绩摘要；本文的每一条结论都可以在
`artifacts/` 的原始报告与逐步轨迹中逐回合复核。数据与原始报告不随 Git 分发；
随仓库提供的保留权重是 `assets/models/best.pt`。

## 当前保留权重：五场景纠偏模型（2026-09-30）

由两阶段微调得到：先在本地采集的五场景专家数据（补入此前从未训练的八字与启停）上微调，
再用模型在环、专家 0.5 混合监督的纠偏数据二次微调。训练细节见下文"训练记录"。

闭环评估口径：`configs/gazebo_feedback.yaml`，五场景 × 各 4 回合，`contact_intercept_v1` 判据，
全部复位合格，无仿真错误、无触地。两个独立评估种子：

| 场景 | seed 10000 | seed 11000 |
|---|---|---|
| 圆周 | 3/4 | 2/4 |
| 正弦 | **4/4** | 2/4 |
| 平滑随机游走 | 2/4 | 2/4 |
| 八字 | 0/4 | 1/4 |
| 启停 | 3/4 | 3/4 |
| 整体 | **12/20（60%）** | 10/20（50%） |

相对上一代保留权重（45%），正弦提升至满贯，圆周与启停改善；八字退化为当前短板
（失视与出画，最小中心距多已逼近 0.5–0.9 m）。命中回合平均 2.4–3.0 s 仿真时间即完成接触。
20 回合的 95% Wilson 区间约 ±20 个百分点，方向性结论需更多回合确认。
原始报告与逐步轨迹见 `artifacts/runs/experiments/corr_suite_10000_20260930/`
与 `corr_suite_11000_20260930/`。

## 训练记录

| 训练 | 数据划分 | 完成情况 | 最佳模型 |
|---|---|---|---|
| 初始 BC | 24 回合、5,227 帧；22 训练 / 2 验证 | 20 轮 | 已删除 |
| 500 轮追加 BC | 沿用初始数据 | 第 286 轮后停止 | epoch 198；验证动作损失 0.000934637；已删除 |
| 100 轮纠偏 BC | 18 回合；15 训练 / 3 验证 | 100 轮 | epoch 99；验证动作损失 0.00329172；已被全速追击模型替代 |
| 全速追击 BC | 500 回合；449 训练 / 51 验证 | 20 轮计划，第 17 轮早停 | epoch 12；验证动作损失 0.00402；已被五场景纠偏模型替代 |
| 五场景纠偏 BC | 五场景专家 173 回合微调 + 模型在环纠偏 135 回合微调 | 8 轮计划，第 7 轮早停 | **epoch 4；验证动作损失 0.00231；当前保留权重** |

各次验证集不同，损失不可横向比较。100 轮训练从纠偏试训最佳权重初始化，优化器重新建立，
不是恢复试训的优化器状态。全速追击训练在退役人工速度上限后，使用 `full_speed_pursuit_v1`
专家重新采集的 500 回合数据（`velocity_max 8`），按验证动作损失选权重并在第 17 轮早停。
五场景纠偏模型的两个数据集均来自本地闭环采集，采集方法见[使用指南](GUIDE.md)第 3 节。
当前模型仍为双帧视觉与自身状态融合，GRU 未启用；历次训练均未执行 PPO。

经验记录：在纯专家数据上适配视觉主干曾在闭环中灾难性失效（分布偏移，40 回合 20 次出画），
在模型在环采集的纠偏数据上做同样的主干适配则正向迁移到闭环——
**离线验证损失与闭环表现可以完全背离，候选权重必须通过闭环复测**。

## 正式验收标准

- 起始两机 `base_link` 中心距为 10±0.2 m，按 `gazebo_base_link_center_enu_to_ned_v2` 基准测量。
- 成功：两机接触，或一步内最小中心距 ≤0.5 m；拦截机撞到目标之外的物体、触地、无效状态与出画均为失败。
- 五种运动各至少 20 回合，整体成功率 ≥90%、各场景 ≥80%，复位全部合格。
- 正式验收保留 seeds 20000+；开发评估（如上表）是调参依据，不是正式验收。

## 局限
